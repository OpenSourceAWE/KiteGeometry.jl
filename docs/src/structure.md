# System definition

A `SystemDefinition` holds one awesIO structure document. Its component types are
generated by `src/build.jl` from the schema vendored at `src/awesio/structure_schema.yml`
from the awesIO commit `gen/awesio.toml` records, one field per required column, in the
schema's order, each quantity's unit in its docstring. Columns and blocks the schema does
not name are kept in `extras`, and the units of those columns in `extra_units`.

```@docs
SystemDefinition
Metadata
load_structure
structure_document
```

## Models

Every component `T{M}` carries a `model::M`: the parameters a tool attaches to a row by
naming a registered model in its `model` column, one extra column per field of `M`. A
component reaches its model's fields as its own, so `tube.EA` reads `tube.model.EA`.

```@docs
AbstractModel
NoModel
register_model!
model_type
```
