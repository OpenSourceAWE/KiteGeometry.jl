# System definition

A `SystemDefinition` holds one awesIO structure document. Its component types are
generated by `src/build.jl` from the schema vendored at `src/awesio/structure_schema.yml`,
one field per required column, in the schema's order; columns and blocks the schema does
not name are kept in `extras`.
